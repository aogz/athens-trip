# Афины — моя поездка

A simple Russian-language PWA for a 2.5-day trip to Athens: day-by-day itinerary, one-tap Google Maps routes, a "show the taxi driver" card in Greek, emergency numbers and basic Greek phrases. Works offline once opened.

Before sharing, fill in `CONFIG` at the top of the script in `index.html` (family phone, trip start date).

Static site — serve the folder over HTTPS (e.g. GitHub Pages) and add it to the home screen.
